# 5. 비압축 유체

속도장을 시간에 따라 갱신하고, 압력 투영으로 유체가 셀 안에서 늘어나거나 줄어드는 오차를 줄이는 단계입니다. 염료 그림과 함께 투영 전후 발산 RMS를 표시하여 압력 계산의 효과를 수치로 확인합니다.

현재 상태: **솔버 구현과 독립 수치 검증 완료 — 공통 실행기 통합, GUI 확인과 캡처 대기**.

## 이번 단계의 기능

- MAC 엇갈린 격자에서 속도 이류·점성 확산·압력 투영을 계산합니다.
- 염료를 갱신된 속도에 따라 옮기고 확산합니다.
- 압력 투영을 켜거나 꺼서 같은 초기 조건의 차이를 비교합니다.
- 마우스로 염료와 속도 증분을 넣어 유체를 밀 수 있습니다.
- 마지막 압력 투영의 전후 발산 RMS와 감소율을 화면에 표시합니다.

영역은 `[-2,2]²`, 기본 해상도는 `64×64`, 고정 시간 간격은 `1/120초`입니다. 동점성 계수는 `0.00015 길이²/초`, 염료 확산 계수는 `0.00002 길이²/초`입니다. 초기 회전장과 세 염료 덩어리에 정규화 위치 `(0.52,0.5)`, 반경0.16의 속도 증분 `(1.2,0.5)`를 더해 압력 보정을 관찰할 수 있게 합니다. 이 단계에서는 부력을 사용하지 않습니다.

## 실행과 조작

이 폴더의 `실행.cmd`를 더블 클릭합니다. 단계별 실행 파일 `실행파일/VectorField.exe`와 `freeglut.dll`이 필요합니다. 공통 실행기에서는 `F5`로 이동합니다.

| 입력 | 동작 |
| --- | --- |
| `P` | 압력 투영 켜기 / 끄기 |
| 왼쪽 버튼을 누른 채 드래그 | 염료와 드래그 방향의 속도 증분 주입 |
| `+`, `-` | 입력 강도 조절 |
| `Space` | 일시정지 / 재개 |
| `R` | 같은 초기 조건으로 복원 |
| `Tab`, `F1`~`F7` | 단계 전환 |
| `F12` | 현재 프레임을 PNG로 저장 |

압력 투영의 영향을 비교할 때는 초기화 후 같은 시간까지 진행하세요. 이미 진행한 장에서 `P`를 바꾸는 조작과, 같은 초기 조건에서 투영 유무를 비교하는 실험은 서로 다른 결과를 만듭니다.

## 어떤 순서로 개발했는가

1. **속도를 셀 면에 배치했습니다.** 오른쪽·왼쪽·위·아래 면의 유출입 차로 셀 발산을 계산합니다.
2. **속도의 점성 확산과 이류를 연결했습니다.** 이전 속도의 복사본으로 역추적하여 갱신 순서가 수평·수직 성분에 섞이지 않게 했습니다.
3. **압력 포아송 방정식을 풀었습니다.** `q=dt×p/ρ`인 압력 충격량을 5점 차분하고 SOR100회, 완화 계수1.7로 근사합니다.
4. **같은 차분 배치로 속도를 보정했습니다.** 이웃 압력 차를 면 속도에서 빼고 닫힌 벽의 법선 속도를0으로 유지했습니다.
5. **보정 전후를 측정했습니다.** 화면의 감소율은 그림의 인상이 아니라 실제 격자 발산으로 계산합니다.

한 시간 단계는 점성 확산 → 투영 → 속도 이류 → 재투영 → 염료 확산·이류 순서입니다. 자세한 방정식과 경계 조건은 [계산과정.md](계산과정.md)에 있습니다.

## 발산 지표 읽기

셀 발산은 단위 `1/초`이며, RMS는 전체 셀 발산 제곱의 평균에 제곱근을 취한 값입니다. 0에 가까울수록 이산 비압축 조건을 잘 만족합니다. 감소율은 투영 전 RMS에 대한 감소분의 비율입니다.

한 단계에 압력 투영을 두 번 실행하면 HUD에는 **마지막 투영**의 전후 값이 남습니다. 서로 다른 시간 단계의 발산을 비교한 지표가 아닙니다. 투영을 끈 경우 전후 값은 같은 현재 발산으로 표시됩니다.

## 검증 기록

공통 FluidGrid 독립 검사 **21개 통과, 실패0개** 중 압력 관련 결과입니다.

| 설정 | 투영 전 RMS | 투영 후 RMS | 결과 |
| --- | ---: | ---: | --- |
| 64² 격자, 반경0.16의 국소 속도 입력 `(2,-1.3)` | 0.8590996313 | 0.03896712157 | 약95.46% 감소 |
| 32² 격자, 발산형 장 `0.8(x,y)`와 닫힌 벽 | 4.381780460 | 0.01541696877 | 90% 감소 기준 통과 |

진단값이 최종 장에서 직접 계산한 RMS와 일치하는지, 투영 뒤에도 모든 벽의 법선 속도가0인지 검사했습니다. 이 표는 독립 테스트의 입력이며 UI 초기 속도 증분과는 구분됩니다. 전체 출력은 단계 보관 시 `검증결과.txt`에 기록합니다. GUI 조작과 PNG 저장은 통합 실행 후 확인 대기 상태입니다.

SOR100회는 유한한 근사이므로 발산이 정확히0이 되지는 않습니다. 높은 해상도에서는 같은 반복 횟수로 남는 오차가 커질 수 있습니다. 벽은 법선 유동이 없는 free-slip 조건이며 점착 벽의 no-slip 모델은 아닙니다.

다음 두 캡처는 같은 초기 조건에서1초까지 진행한 뒤 비교하도록 계획했습니다. 현재는 실제 캡처 대기 상태입니다.

| 파일 | 조건 |
| --- | --- |
| `캡처/01_투영적용.png` | 압력 투영 켬, 시뮬레이션1초 |

색의 모양과 함께 HUD의 발산값을 읽어야 합니다. 보기 비슷한 장이라도 셀의 유출입 오차는 다를 수 있습니다.
