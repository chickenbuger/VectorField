# 5단계: 압력 투영으로 비압축 조건 맞추기

이 단계는 주어진 장으로 염료만 옮기던 4단계에 속도의 점성 확산, 속도 이류, 압력 투영을 연결합니다. 구현은 [`FluidGrid.h`](../opgnel_project_smoke/FluidGrid.h)의 `Step`, `Project`에 있습니다.

## 계산 모델

2차원 비압축 유동의 속도 방정식과 연속 방정식을 단순화하여 사용합니다.

```text
∂u/∂t + (u·∇)u = -(1/ρ)∇p + ν∇²u + f
∇·u = 0
```

`u=(u,v)`는 속도, `ν`는 동점성 계수, `ρ`는 일정한 기준 밀도입니다. 영역 길이는 4, 기본 격자는 `64×64`, 간격은 `h=0.0625`입니다. `ν` 기본값은 `0.00015 길이²/초`입니다.

셀 중심에는 염료와 압력, 수직 면에는 수평 속도 `u`, 수평 면에는 수직 속도 `v`를 둡니다. 이 MAC 배치는 이웃 압력 차로 보정한 면 속도를 그대로 발산 계산에 사용할 수 있게 합니다.

## 한 시간 단계의 실제 순서

`Step(dt,viscosity,diffusion,project,advectVelocity,buoyancy)`는 다음 순서로 동작합니다.

1. 부력이 켜져 있으면 수직 면 속도에 외력 증분을 더합니다.
2. 두 속도 성분에 암시적 점성 확산을 적용합니다. 4단계의 확산과 같은 5점 식을 Gauss–Seidel **24회**로 풉니다.
3. 압력 투영이 켜져 있으면 속도를 투영합니다.
4. 속도 이류가 켜져 있으면 각 면에서 이전 속도로 역추적하여 이전 면 속도를 쌍선형 보간합니다.
5. 속도 이류와 투영이 모두 켜져 있으면 다시 투영합니다. 속도 이류가 만든 발산을 줄이는 과정입니다.
6. 갱신된 속도로 염료를 확산하고 이류합니다.

속도 이류는 이전 `u,v` 배열의 복사본만 읽으므로, 수평 속도를 먼저 갱신한 결과가 같은 단계의 수직 속도 역추적에 섞이지 않습니다. 점성·염료 확산 계수는 유한한 양수만 적용하고 최대 1로 제한합니다. 시간 간격은 유한한 양수일 때 최대 0.1초로 제한됩니다.

## 발산의 차분식

셀 `(i,j)`의 오른쪽·왼쪽 면 속도를 `u[i,j]`, `u[i-1,j]`, 위·아래 면 속도를 `v[i,j]`, `v[i,j-1]`라 하면 다음과 같습니다.

```text
div[i,j] = (u[i,j] - u[i-1,j] + v[i,j] - v[i,j-1]) / h
```

양의 값은 셀에서 나가는 양이 들어오는 양보다 많다는 뜻입니다. 비압축 조건은 각 셀의 이 값이 0이 되는 것입니다. 단위는 `1/초`입니다.

예를 들어 `h=0.0625`, 오른쪽·왼쪽 수평 속도가 각각 `0.10`, `0.08`, 수직 속도 차가 0이면 발산은 `0.02/0.0625=0.32 1/초`입니다.

## 압력 포아송 방정식

시간 간격과 기준 밀도를 합친 압력 충격량 `q=dt×p/ρ`를 풉니다. 속도 보정과 포아송 방정식은 다음과 같습니다.

```text
u_corrected = u_provisional - ∇q
∇²q = div_provisional
```

따라서 저장된 `q`는 절대 압력 자체가 아니며 단위는 `길이²/초`입니다. 각 내부 셀에서 5점 차분을 적용하면 다음 식을 얻습니다.

```text
q_target = (이웃 q의 합 - h² × div) / 이웃 수
```

벽에서는 법선 압력 기울기가 0인 Neumann 조건을 사용합니다. 벽 밖 이웃은 자기 셀과 같은 압력을 가진 것으로 처리할 수 있으므로, 구현에서는 그 이웃과 대각 계수를 함께 제거합니다. 내부 셀은 이웃 4개, 벽 옆 셀은 3개, 모서리 셀은 2개입니다.

압력 배열을 0으로 초기화하고 SOR 반복을 **100회**, 완화 계수 `ω=1.7`로 수행합니다.

```text
q ← q + 1.7 × (q_target - q)
```

닫힌 벽에서 법선 속도가 0이므로 전체 발산 합은 면 차분이 서로 상쇄되어 0입니다. 이는 Neumann 포아송 문제의 양립 조건입니다. 압력에는 임의의 상수를 더할 수 있지만 속도에는 압력 차만 쓰므로 그 상수는 영향을 주지 않습니다.

## 면 속도 보정

압력을 푼 뒤 내부 면의 속도를 다음처럼 갱신합니다.

```text
u[i,j] ← u[i,j] - (q[i+1,j] - q[i,j]) / h
v[i,j] ← v[i,j] - (q[i,j+1] - q[i,j]) / h
```

발산과 압력 기울기에 같은 면·셀 배치를 사용하므로 두 연산을 합치면 앞서 푼 5점 라플라시안과 일치합니다. 모든 벽의 법선 속도는 정확히 0으로 고정하고 접선 속도는 가장 가까운 내부값으로 복사합니다. 따라서 벽은 통과할 수 없지만 접선 방향 미끄러짐을 허용하는 free-slip 경계입니다. 점착 벽의 no-slip 조건은 구현하지 않습니다.

## 진단값과 실제 검증

`DivergenceRms()`는 전체 `N²` 셀에서 다음 값을 계산합니다.

```text
RMS = sqrt(Σ div[i,j]² / N²)
```

`divergenceBeforeProjection`, `divergenceAfterProjection`은 마지막 `Project()` 호출의 RMS, `maxDivergenceBefore`, `maxDivergenceAfter`는 최대 절댓값입니다. 한 단계에 두 번 투영하면 마지막 투영의 전후 값이 남습니다. 투영을 끄면 두 진단값 모두 현재 발산으로 설정됩니다.

독립 MSVC C++14 Release 테스트에서 다음 값을 얻었습니다.

| 설정 | 투영 전 RMS | 투영 후 RMS | 전 최대 절댓값 | 후 최대 절댓값 |
| --- | ---: | ---: | ---: | ---: |
| 64×64, 정규화 위치 `(0.46,0.54)`, 반경0.16, 속도 증분 `(2,-1.3)` | 0.8590996313 | 0.03896712157 | 5.714772032 | 0.1649796917 |
| 32×32, 발산형 장 `0.8(x,y)`와 닫힌 벽 | 4.381780460 | 0.01541696877 | 별도 기록 안 함 | 별도 기록 안 함 |

국소 힘 테스트의 RMS 감소율은 약 **95.46%**입니다. 검증은 95% 이상 감소, 진단값과 실제 최종 장의 RMS 일치, 모든 벽의 법선 속도 0을 확인합니다. 발산형 장 테스트는 전역의 낮은 주파수 오차를 포함하며, 90% 이상 감소를 기준으로 검사합니다.

100회 반복은 발산을 정확히 0으로 만드는 보장이 아닙니다. 잔여 발산을 표시하여 수치 오차를 관찰할 수 있게 합니다. 특히 높은 해상도에서는 같은 반복 횟수로 남는 오차가 커질 수 있습니다. 압력의 수렴 허용 오차를 자동으로 맞추는 방식이나 다중격자는 사용하지 않습니다.

이 모델은 일정 밀도의 2차원 비압축 유동입니다. 충격파, 음향, 압축성, 실제 기체의 상태방정식은 다루지 않습니다. 염료는 시각화용 추적량이며 질량 밀도의 변화로 포아송 방정식을 바꾸지 않습니다.

참고: [Jos Stam, Stable Fluids, SIGGRAPH 1999](https://graphics.stanford.edu/courses/cs448-01-spring/papers/stam.pdf). 단계별 연산 분리와 압력 투영 접근을 참고했습니다. 여기의 공간 배치는 MAC 격자이며, 차분식과 실제 반복 횟수는 위 설명을 따릅니다.
