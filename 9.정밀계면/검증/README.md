# 9단계 독립 계면 검증기

이 검증기는 공통 앱의 `SharpInterfaceTests.h`와 별도로 작성했습니다. OpenGL을 띄우지 않고 새 계면 솔버를 실행하며, 실제 MAC 면 속도·셀 압력·레벨셋 값을 직접 읽어 기준식과 비교합니다. 공통 자동 검사의 개수에 이 검증기의 조건을 중복 합산하지 않습니다.

## 실행

저장소 루트에서 C++14 컴파일러와 CMake를 사용합니다. Windows에서는 Visual Studio 2022 C++ 개발 도구가 필요합니다.

```powershell
cmake -S "9.정밀계면/검증" -B build/stage9-independent-review -G "Visual Studio 17 2022" -A x64
cmake --build build/stage9-independent-review --config Release
.\build\stage9-independent-review\Release\independent_interface_review.exe
```

실제 실행 출력은 상위 폴더의 [독립검증결과.txt](../독립검증결과.txt)에 보관합니다. 실행 시간은 이 PC에서 OpenGL 표시를 제외하고 측정한 값입니다.

## 독립적으로 다시 계산하는 양

셀 중심 레벨셋을 `a`, 이웃을 `b`라 하면 두 부호가 다를 때 교차 위치를 다음처럼 구합니다. 음수 쪽이 물이며 기본 물 밀도는 1,000입니다.

$$
\theta=\frac{|a|}{|a|+|b|},\qquad
\beta_f=\frac1{\theta\rho_a+(1-\theta)\rho_b}.
$$

같은 재료를 잇는 면에서는 `beta=1/rho`입니다. 검증기 쪽에서 이 식을 다시 계산하고 코어가 제공한 면 계수·교차 비율과 비교합니다. 면 계수를 그대로 정답으로 복사하지 않습니다.

발산은 모든 셀에서 실제 네 면 속도의 차이를 셀 간격으로 나누고 RMS로 합산합니다. 닫힌 용기의 경계 법선 면 속도도 직접 읽습니다.

압력 투영의 운동 에너지는 각 내부 면 성분의 이산 질량 `h²/beta_f`를 사용해 `0.5*m_f*u_f²`를 합산합니다. 이는 이 투영 연산의 질량 가중 내적이며, 이류·중력·분출원·레벨셋 보정까지 포함한 전체 시간 단계의 에너지 보존을 주장하는 값은 아닙니다.

PCG의 압력은 상수만큼 달라도 같은 속도를 만듭니다. 따라서 압력 오차는 실제 압력 `p`에 시간 간격을 곱한 충격량 `q=dt*p`에서 정확해와의 평균 차이를 뺀 뒤 최댓값을 구합니다. 압력의 절댓값을 임의의 한 셀 값에 맞춰 비교하지 않습니다.

제조한 압력장은 이산 압력 연산과 투영의 일관성을 검증합니다. 별도의 연속체 정확도·해상도 수렴을 모두 증명하는 시험으로 해석하지 않습니다. 정수압 비교는 평면 계면의 구간 길이 가중이 중간점 근사보다 압력 계산을 개선하는지 직접 확인하는 시험입니다. 해상도마다 계면이 셀 안에서 차지하는 위치가 달라지므로 중간점 근사의 오차가 해상도에 따라 단조롭게 줄어든다고 요구하지 않습니다.

## 해석 범위

9단계는 8단계의 입자·캐리어 항력 교환과 별도의 격자 두 재료 모델입니다. 두 상이 하나의 MAC 속도와 압력 투영을 공유하고, 계면에서 밀도가 달라집니다. 여기서 검증하는 연속 압력 조건은 표면장력 계수를 0으로 둔 조건입니다. 표면장력의 압력 점프나 압축성 기포·열·상변화는 이 검증의 범위가 아닙니다.

레벨셋에서 복원한 물 면적의 변화는 별도 수치로 보고합니다. 전체 면적을 보정하더라도 지역별 재료 질량·엄밀한 보존형 VOF 이류·날카로운 모든 형상의 기하를 정확히 보존했다는 뜻은 아닙니다. 전체 진행 결과는 기록한 두 밀도·초기 조건·입력에서의 결과입니다.
