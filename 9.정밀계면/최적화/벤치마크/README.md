# 9단계 성능 측정과 독립 대조

기준 버전은 불변 커밋 `75cf82b`의 `SharpInterfaceSimulation.h`입니다. 설정할 때 Git에서 이 파일을 읽어 빌드 폴더에 보관하고 클래스 이름만 바꿉니다. 현재 코어와 기준 코어를 같은 실행 파일에 동일한 컴파일 옵션으로 넣습니다. 원본 9단계의 개발 기록과 수치 검증은 상위 폴더에 그대로 남습니다.

## 다시 실행

Visual Studio 2022의 C++ 개발 도구·CMake·Git를 설치한 Windows에서, 기준 커밋을 포함하는 Git 복제본의 루트를 기준으로 실행합니다. `cmake`가 PATH에 없으면 Visual Studio의 CMake 실행 파일 경로를 사용합니다.

```powershell
cmake -S "9.정밀계면/최적화/벤치마크" -B build/perf-baseline -G "Visual Studio 17 2022" -A x64
cmake --build build/perf-baseline --config Release
Push-Location "9.정밀계면/최적화"
..\..\build\perf-baseline\Release\baseline_profile.exe
..\..\build\perf-baseline\Release\compare_interface_performance.exe
Pop-Location
```

`baseline_profile`은 기준 헤더의 계산 블록 경계에 `steady_clock` 측정을 넣은 별도 계측 버전입니다. 계측한 시간은 전체 성능의 공식 전후 비교에 쓰지 않고 병목 비중을 찾는 데 사용합니다. 새 코어를 최적화한 뒤에도 기준 프로파일은 기준 커밋만 읽으므로 기준값이 바뀌지 않습니다.

`compare_interface_performance`는 계측하지 않은 기준 코어와 현재 코어를 비교합니다. x64 Release, C++14, MSVC `/O2 /fp:precise`를 양쪽에 동일하게 적용합니다. OpenGL, 창 표시, 파일 저장과 검증 배열 순회는 측정하는 `Step()` 구간에 포함하지 않습니다. GUI FPS나 실제 표시 프레임 시간의 결과로 해석하지 않습니다.

## 측정 조건

- 격자 48², 고정 시간 간격 1/120초, 기본 댐과 분출원, 600개 고정 스텝으로 시뮬레이션 시간 5초를 진행합니다. 마우스나 추가 `Stir()` 입력은 없습니다.
- 기체 밀도 80과 1.2를 각각 같은 초기 조건에서 실행합니다. 물 밀도, CFL 목표, 압력 잔차 허용값을 성능 비교를 위해 낮추지 않습니다.
- 프로세스 안에서 각 코어를 24²·20스텝 예열하고, 각 조건을 새 상태로 3회 반복합니다. 홀수 반복은 기준→최적화, 짝수 반복은 최적화→기준 순서입니다. 두 코어의 CPU 작업을 동시에 실행하지 않습니다.
- 각 `Step()`의 `steady_clock` 경과 시간을 저장합니다. 600개 시간의 합, 최근접 순위법 p50·p95·최댓값, 세 번의 전체 시간 중 중앙값을 보고합니다.
- 검증과 CSV 기록은 각 `Step()` 측정 직후 수행하므로 보고하는 합은 계산 구간의 경과 시간입니다. 600스텝 전체 루프의 사용자 체감 시간과는 다릅니다.
- CPU 전원·온도와 다른 백그라운드 프로그램을 완전히 통제한 하드웨어 벤치마크는 아닙니다. 공식 비교 중에는 다른 에이전트의 빌드·벤치·GUI 실행이 겹치지 않도록 조율합니다.

## 함께 확인하는 계산 상태

각 고정 스텝 직후 실제 네 MAC 면에서 발산 RMS를 다시 합산하고, 닫힌 벽 속도, 유한값, 상 분율 범위, 보정 후 면적, 시간과 추정 CFL을 확인합니다. `pressureIterations`와 `pressureConverged`는 고정 스텝의 **마지막 내부 부단계**에 남은 값입니다. 총 내부 스텝 수와 마지막 부단계 반복 수의 합을 구분해 저장합니다.

고정 계면의 동일 속도장을 투영한 쌍에서는 MAC 면 속도 최대 차이 <1e-8, 평균 기준값을 제거한 압력 RMS 차이 <1e-4와 최적화 코어의 수렴을 요구합니다. 전체 600스텝의 마지막 실제 배열도 비교합니다. 측정 전에 정한 허용 범위는 레벨셋 RMS가 셀 크기의 0.1% 이하, 속도·압력 RMS 차이가 기준 RMS(최소 1)의 0.1% 이하, 보정 면적 절대 차이가 1e-8 이하입니다. 실제 차이는 허용값과 별도로 CSV에 남깁니다. 비선형 이류와 반복 해법의 부동소수점 계산 순서가 달라질 때 생기는 작은 차이를 숨기지 않습니다.

같은 버전·밀도의 세 반복에 대해서는 최종 `phi`, 압력, 염료와 두 MAC 면 배열을 비교합니다. 최대 차이 1e-12 이하를 요구해 반복 실행의 결정성을 확인합니다. 이 배열 비교는 실제 PNG를 비교한 시각 검증과 구분합니다.

성능 측정과 별도로 원래 [독립 계면 검증기](../../검증/README.md)를 현재 코어로 다시 빌드해 실행합니다. 형식적인 성능 개선만으로 수치 해법의 정확성을 판단하지 않습니다.

후보 탐색 출력은 작업 버퍼·활성 경계 띠·IC(0)·MIC(0)을 순서대로 비교한 보충 기록입니다. 검증 순회까지 포함한 단회 전체 경과 시간이므로, 예열과 3회 반복을 적용하고 `Step()`만 측정한 공식 결과와 같은 기준의 성능 값으로 합치지 않습니다. 이 폴더의 정식 재현 하네스는 불변 기준과 채택한 최종 코어의 비교를 지원합니다.
