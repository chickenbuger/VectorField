# 4단계: 격자 위의 이류와 확산

연산 구현은 [`FluidGrid.h`](../opgnel_project_smoke/FluidGrid.h), 수치 검증은 [`FluidGridTests.h`](../tests/FluidGridTests.h)에 있습니다. 이 단계는 주어진 속도장으로 염료를 옮깁니다. 염료가 속도장을 바꾸거나 압력이 속도를 보정하지는 않습니다.

## 공간·시간·자료 배치

계산 영역은 `[-2,2] × [-2,2]`이며 한 변의 길이는 4입니다. 기본 해상도는 `N=64`, 셀 간격은 `h=4/N=0.0625`입니다. 셀 인덱스는 `i,j=1,…,N`이며 중심의 실제 좌표는 다음과 같습니다.

```text
x = -2 + (i - 0.5) h
y = -2 + (j - 0.5) h
```

염료 `d[i,j]`는 셀 중심에 저장합니다. 속도는 다음 단계의 압력 계산에도 사용할 수 있도록 MAC 엇갈린 격자에 저장합니다. `u[i,j]`는 셀 오른쪽 면, `v[i,j]`는 셀 윗면의 속도입니다. 외부의 `U(i,j)`, `V(i,j)`는 양쪽 면 속도의 평균으로 셀 중심 값을 돌려줍니다.

마우스 주입과 표본 추출 API는 정규화 좌표 `(s,t)∈[0,1]²`를 받습니다. 실제 좌표와의 관계는 `x=4s-2`, `y=4t-2`입니다. 속도 단위는 영역 길이/초, 염료는 무차원 추적 농도입니다. 시간 간격 `dt`는 초이며 솔버는 한 호출에서 최대 `0.1초`까지 계산합니다. 큰 시간 간격을 잘라 계산하므로 호출자는 작은 고정 간격으로 반복해야 합니다.

## 주어진 속도장

`SetPresetVelocity(type,strength)`는 1단계의 장을 각 속도 면의 실제 좌표에서 계산합니다. 예를 들어 회전장은 다음과 같습니다.

```text
u(x,y) = -strength × y
v(x,y) =  strength × x
```

균일장은 `(strength,0.25×strength)`입니다. 벽에서는 법선 속도를 0으로 고정하므로 경계 부근의 장은 무한한 평면에서의 해석적 장과 달라집니다. `StepDye`는 이 속도를 변경하지 않습니다.

## 1. 암시적 확산

염료 확산 방정식은 다음과 같습니다.

```text
∂d/∂t = κ ∇²d
```

확산 계수 `κ`의 단위는 길이²/초이며 기본값은 `0.00002`입니다. 후진 오일러 시간 적분과 5점 라플라시안을 적용합니다.

```text
a = κ dt / h²
(1+4a) d_new[i,j]
  - a(d_new[i-1,j] + d_new[i+1,j] + d_new[i,j-1] + d_new[i,j+1])
  = d_old[i,j]
```

Gauss–Seidel 반복을 **24회** 수행합니다. 각 셀을 순서대로 갱신하므로 같은 반복에서 이미 계산한 이웃값을 바로 사용합니다. 한 번의 갱신식은 다음과 같습니다.

```text
d[i,j] = (d_old[i,j] + a × 이웃 네 값의 합) / (1+4a)
```

예를 들어 `N=64`, `dt=1/60`, `κ=0.00002`이면 `a≈0.0000853333`입니다. 입력 확산 계수는 유한한 양수일 때만 적용하며 최대 1로 제한합니다. 벽 바깥의 염료값은 가장 가까운 내부값으로 복사하여 `∂d/∂n=0`, 즉 확산에 의한 벽 통과가 없도록 합니다.

## 2. 역추적 이류

확산된 염료를 현재 속도로 옮깁니다. 셀 중심 정규화 좌표를 `p`라 하면, 염료가 한 시간 전 어디 있었는지 역으로 추정합니다.

```text
p_back = p - (dt/4) × velocity(p)
d_next(p) = d_diffused(p_back)
```

`dt/4`는 실제 길이 단위의 속도를 정규화 좌표 변화량으로 바꾸는 계수입니다. 역추적 위치는 `[0,1]²`로 제한합니다. 이 방법은 1차 역추적을 사용하는 semi-Lagrangian 이류입니다.

역추적 위치는 보통 셀 중심 사이에 놓이므로 네 셀의 염료를 쌍선형 보간합니다. 격자 좌표의 소수 부분이 `α,β`이면 다음과 같습니다.

```text
d = (1-β)[(1-α)d00 + αd10] + β[(1-α)d01 + αd11]
```

가중치가 음수가 아니고 합이 1이므로 보간만으로 주변값보다 더 큰 최고 농도를 만들지 않습니다. 셀 중심 염료와 면 속도는 저장 위치가 다르므로 각각의 좌표 오프셋을 적용하여 보간합니다.

## 염료 주입

`AddDye(s,t,amount,radius)`는 반경 안의 셀에 다음 가중치로 농도를 더합니다.

```text
r² = ((s_cell-s)² + (t_cell-t)²) / radius²
w = max(0,1-r²)²
d ← clamp(d + amount × w, 0, 10)
```

반경은 정규화 좌표 단위이며 최소 `0.75/N`으로 제한합니다. `amount`는 함수 호출 한 번에 더하는 농도입니다. 초당 주입률을 표현하려면 호출자가 `amount=rate×dt`로 넣습니다.

## 실제 검증

독립 MSVC C++14 Release 실행에서 다음을 확인했습니다.

- 농도 `0.75`를 전체에 채우면 확산과 역추적 후에도 모든 셀에서 같은 값을 유지합니다. 허용 오차는 `1e-9`입니다.
- 선형 회전장의 면 속도를 보간한 값은 벽에서 떨어진 지점의 해석적 값과 `1e-9` 이내로 일치합니다.
- 균일 속도 `(1,0.25)`로 `0.05초×20회` 이류한 염료의 정규화 무게중심 이동량은 `(0.25,0.0625)`입니다. 길이4 영역에서 1초 동안 실제로 `(1,0.25)` 이동한 결과입니다.
- `48×48`, `κ=0.04`, `0.05초×12회` 확산에서 최고 농도는 `2.999742804 → 1.055901638`로 감소했습니다. 염료 셀값 합의 상대 오차는 `7.28×10⁻¹⁶`이었습니다. 이 결과는 정지 속도장과 해당 테스트 설정에 대한 값입니다.

semi-Lagrangian 이류는 농도 총량을 정확히 보존하는 방법이 아닙니다. 보간에 따른 수치 확산도 생기므로, 명시한 확산 계수가 0이어도 날카로운 염료 경계가 점차 흐려질 수 있습니다. 24회 확산 반복은 유한한 근사이며 큰 확산 계수·높은 해상도에서 정확한 선형계 해와 차이가 커질 수 있습니다.

참고: [Jos Stam, Stable Fluids, SIGGRAPH 1999](https://graphics.stanford.edu/courses/cs448-01-spring/papers/stam.pdf). 역추적 이류와 암시적 확산을 분리하는 계산 접근을 참고했습니다.
